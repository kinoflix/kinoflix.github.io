# Frontend

Bu qovluğu repository kökündə `/football/` kimi yerləşdirin.

Yeganə məcburi frontend parametri: `js/config.js` → `WORKER_BASE_URL`.

API key bu qovluqda saxlanmır. Tam quraşdırma paket kökündəki `README.md`-dədir.

Standalone HTML faylını `file://` ilə açmaq əvəzinə HTTP serverdən istifadə edin.
Tema mövcud `flix-theme` və `data-theme` sistemi ilə eynidir.

Bu gün, canlı, sabah, tarix/liqaya/statusa görə filtr, matç/profil pəncərələri,
liqalar/cədvəl/bombardirlər, favoritlər, tarixçə və paylaşım burada idarə olunur.
API paketindən gəlməyən məlumatlar uydurulmur.
